# College Event Feedback Analysis — Task 3

This project analyzes student feedback from a college event using Python and Google Colab. It includes rating visualizations, sentiment analysis, and key recommendations for event organizers.

## Files Included
 `College_Event_Feedback_Analysis.ipynb`: Full notebook with code, charts, and insights
 `student_feedbackT3.csv`: Raw feedback data
 `assets/`: Screenshots of visual outputs
 ![Bar Chart](assets/bar_chart.png)
![Radar Chart](assets/radar_chart.png)
![Word Cloud](assets/wordcloud.png)


## Visualizations
 Bar Chart: Average ratings per category
 Radar Chart: Holistic view of feedback dimensions
 Sentiment Breakdown: Positive, Neutral, Negative distribution
 Word Cloud: Common themes from student comments

## Insights
 Students rated concept clarity and supportiveness highest
 Sentiment analysis shows majority positive feedback
 Word cloud highlights terms like “supportive”, “clear”, “structured”

## Recommendations
 Continue emphasizing clarity and student support
 Balance assignment difficulty based on feedback
 Maintain structured delivery and presentation use

## Tools Used
 Python, Pandas, Matplotlib, Seaborn
 TextBlob for sentiment analysis
 WordCloud for visual text mining
 Google Colab for execution
